# 演示脚本

> 版本：0.1.0

## 演示环境

- 本地 Agent Runtime
- 项目：帮助中心搜索体验优化

## 演示一：只整理 Context

1. 上传会议记录和用户反馈
2. Agent 分类、标注、检查冲突
3. 人工确认 Context 更新
4. 查看最终 Context 索引

## 演示二：Context → PRD

1. 基于已有 Context 开始 PRD 准备
2. 写前对齐：背景卡 + 决策账本
3. 人工确认关键决策
4. PRD 主体生成 → 确认
5. PRD 细节补充 → 审核 → 交付

## 演示三：修改与重规划

1. 修改需求范围
2. Agent 分析影响范围
3. 展示受影响和保留内容
4. 人工确认新计划
5. 返回正确节点继续
