做什么：
● 对 PRD 进行完整性检查
● 模拟资深 PM / 研发 / 测试三方视角进行评审
● 输出问题清单和风险等级
● 输出具体修改建议
● 生成评审报告
● 支持修改后复评
● 支持 PRD 质量评分
不做什么：
● 不直接代替 PM 生成完整 PRD
● 不替代正式需求评审会
● 不承诺自动判断业务方案一定正确
● 不直接生成最终技术方案
● 不直接替代测试用例管理系统
● 不做复杂项目管理和排期系统
