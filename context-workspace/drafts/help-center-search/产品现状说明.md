# 帮助中心搜索现状

## 检索规则

帮助中心当前只匹配文章标题和后台配置的标签。检索服务不理解句子含义，也不会把口语词自动映射到正式产品术语。

## 无结果页

没有命中时，页面展示固定的热门问题列表。热门问题由运营按月调整，不根据本次搜索词变化。

## 数据条件

当前检索服务尚未接入查询词日志，无法直接统计无结果率。客服反馈是现阶段识别搜索问题的主要来源之一。
