会议主题：帮助中心搜索体验优化讨论会
会议时间：周三 15:00-15:40
参会人：产品经理小林、客服负责人阿敏、研发负责人老周、运营同学小夏
小林：最近客服那边反馈，用户在帮助中心搜不到答案的问题变多了。今天先看是不是要做搜索优化，如果要做，先确定一个最小版本。
阿敏：客服这边最近两周统计了一下，大概 38% 的咨询，其实帮助中心里已经有文章，但用户没搜到。最常见的是退款、发票、账号登录、修改手机号这几类。用户经常搜的是口语词，比如“退钱”“开发票”“手机号不用了”，但文章标题写的是“退款规则”“发票申请流程”“账号安全设置”。
小夏：运营这边之前维护过一份高频问题表，但没有和搜索词打通。现在帮助中心文章大概 120 篇，标题比较正式，用户搜口语词确实不容易命中。我们可以先维护一批关键词别名。
老周：如果做完整的智能搜索，这期可能来不及。要接向量检索，还要处理召回和排序，至少要两到三周。短期可以先做两件事：第一，零结果页推荐热门问题；第二，给高频问题配置关键词别名。这个改动比较小，一周内可以做完。
小林：那第一期先不做智能问答，也不做完整语义搜索。先解决用户搜不到已有文章的问题。目标是降低零结果率，让用户能更快找到已有答案。
阿敏：客服可以提供最近两周 Top 50 搜索词和对应咨询问题。我希望结果里能标出来哪些问题原来已经有文章，哪些是真的没有文章。
小夏：运营可以负责关键词别名表维护，但需要产品给一个格式。比如一个标准问题，对应多个用户可能会搜的词。
老周：还要注意日志里可能有手机号、订单号这类信息，导出搜索词前要做脱敏。这个要和数据同学确认一下。
小林：好。那这次先定三个动作：客服给 Top 50 搜索词，运营整理关键词别名表，产品出一个最小版本方案。研发这边评估零结果页推荐和关键词别名配置的实现。下周二我们再过一次方案。
阿敏：我周五下班前给 Top 50 搜索词。
小夏：我拿到词以后，下周一给第一版关键词别名表。
老周：我这周五前给一个技术评估，主要说清楚能做什么，不能做什么。
小林：我下周二前出 PRD 初稿，先不写完整智能搜索，只写第一期。
