# PRD 可写状态规则

## READY

同时满足：

- 问题和目标已有来源且相互一致；
- 本期范围与明确不做项已确认；
- 所有阻塞决策均已由人确认；
- 上下游依赖足以支撑主体写作；
- 没有会推翻核心流程的冲突。

## NEEDS_CONFIRMATION

材料足以形成建议，但仍有少量关键选择需要人确认。进入 CP-P01，不得直接进入 CORE 写作。

## BLOCKED

缺少问题证据、目标、范围或关键依赖，无法给出可信选项。返回 Context 分析或要求补充材料。

## 决策状态

- `CONFIRMED`：有明确人工确认或稳定 Context 依据。
- `PENDING`：已形成可选方案，等待人确认。
- `BLOCKED`：缺少形成有效选项的信息。
- `SUPERSEDED`：已被新决策明确替代。
