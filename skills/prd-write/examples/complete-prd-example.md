## 1. 背景与问题

### 当前问题

用户在管理大型项目时，需要维护复杂的任务层级关系。现有系统只支持平铺列表，导致：
1. 无法直观展示任务之间的依赖关系
2. 难以区分主任务和子任务
3. 批量操作效率低下

### 用户反馈

- 来源：`context/user-feedback/2026-08-15-project-hierarchy.md`
- 核心诉求："希望能像思维导图一样管理任务"

---

## 2. 产品目标与非目标

### 产品目标

1. **提升结构化程度**：支持多层级节点组织，清晰展示任务关系
2. **提升操作效率**：支持批量操作，减少重复劳动
3. **保持易用性**：不增加新手用户的学习成本

### 非目标（明确不做）

- ❌ 不做自动任务调度和智能推荐
- ❌ 不做节点间的复杂依赖计算（如关键路径分析）
- ❌ 不做项目模板市场

---

## 3. 目标用户与场景

### 目标用户

- **项目经理**：需要管理 10+ 成员的中大型项目
- **团队负责人**：需要拆解复杂任务为可执行子任务
- **个人用户**：需要管理个人项目的任务结构

### 典型场景

1. **场景 1：创建项目结构**
   - 项目经理创建新项目后，快速搭建任务层级
   - 从模板快速初始化项目结构（v1.1 规划）

2. **场景 2：任务拆解**
   - 团队负责人将主任务拆解为多个子任务
   - 为每个子任务分配负责人和截止日期

3. **场景 3：批量调整**
   - 项目范围变化时，批量移动或删除节点
   - 批量导入外部任务清单

---

## 4. 本期范围与明确不做

### 在范围内

1. **节点 CRUD**：创建、查看、编辑、删除项目节点
2. **层级管理**：支持最多 5 层嵌套，拖拽调整层级
3. **批量操作**：批量导入（CSV）、批量导出、批量删除
4. **权限控制**：按角色控制节点的查看和编辑权限

### 明确不做

1. **节点模板**：预定义的节点结构模板（v1.1 规划）
2. **版本对比**：节点历史版本的对比和回滚（v1.2 规划）
3. **自动化规则**：基于条件的节点自动创建或状态变更
4. **甘特图视图**：时间轴视图（需要先完成日期字段支持）

## 5. 核心用户流程

### 流程 1：创建节点

```
用户动作                   系统响应
─────────────────────── → ───────────────────────
1. 点击"新建节点"按钮     → 弹出节点编辑表单
2. 输入节点名称和描述     → 实时校验名称长度
3. 选择父节点（可选）     → 展示可选的父节点列表
4. 点击"保存"             → 保存节点，刷新列表
                          → 提示"节点创建成功"
```

### 流程 2：批量导入节点

```
用户动作                   系统响应
─────────────────────── → ───────────────────────
1. 点击"批量导入"按钮     → 弹出文件选择框
2. 选择 CSV 文件上传      → 校验文件格式和内容
3. 预览导入结果           → 展示导入预览（成功/失败）
4. 确认导入               → 执行导入，展示导入报告
                          → "成功 X 条，失败 Y 条"
```

### 流程 3：调整节点层级

```
用户动作                   系统响应
─────────────────────── → ───────────────────────
1. 拖拽节点到目标位置     → 实时展示拖拽预览
2. 释放鼠标               → 校验目标层级是否合法
                          → 更新节点层级
                          → 提示"层级调整成功"
```

## 6. 功能概述

1. **节点管理**：创建、编辑、删除项目节点
2. **层级组织**：拖拽调整节点层级，最多支持 5 层嵌套
3. **批量操作**：批量导入、导出、删除节点
4. **权限控制**：按角色配置节点的查看和编辑权限
5. **搜索过滤**：按名称、状态、负责人搜索节点

---

## 7. 非功能需求

### 性能要求

- **列表加载**：100 个节点的列表页在 2 秒内加载完成
- **批量导入**：1000 条节点数据在 30 秒内完成导入
- **拖拽响应**：拖拽操作的视觉反馈延迟不超过 100ms

### 安全要求

- **权限隔离**：查看者不能编辑或删除节点
- **敏感操作确认**：批量删除需要二次确认
- **数据导出控制**：仅管理员和所有者可导出完整项目数据

### 可用性要求

- **移动端支持**：核心功能（创建、查看、编辑）支持移动端访问
- **离线提示**：网络断开时明确提示，不静默失败
- **操作可撤销**：删除节点后 5 秒内可撤销

## 10. 功能详细规则与状态

### 10.1 节点字段定义

| 字段 | 类型 | 必填 | 说明 | 校验规则 |
|------|------|------|------|---------|
| node_id | String | 是 | 节点唯一标识 | 自动生成 |
| node_name | String | 是 | 节点名称 | 1-50 字 |
| node_desc | Text | 否 | 节点描述 | 不超过 500 字 |
| parent_id | String | 否 | 父节点 ID | 必须存在且不能是自己 |
| node_status | Enum | 是 | 节点状态 | active / archived |
| created_by | String | 是 | 创建人 | 用户 ID |
| created_at | Datetime | 是 | 创建时间 | 自动生成 |

### 10.2 节点状态流转

```
[新建] → active
active → archived（归档）
archived → active（取消归档）
```

### 10.3 层级限制规则

- 最大深度：5 层
- 当前层级 = 4 时，不允许添加子节点
- 拖拽时自动计算目标层级，超过限制则拒绝

### 10.4 批量导入规则

- **CSV 格式要求**：
  ```
  node_name, parent_name, node_desc
  主任务1, , 描述1
  子任务1-1, 主任务1, 描述2
  ```
- **导入逻辑**：
  - 逐行解析，parent_name 为空则创建为根节点
  - parent_name 不存在则创建失败
  - 同名节点在同一父节点下视为重复，跳过

## 12. 边界与异常处理

### 12.1 创建节点异常

| 异常情况 | 系统处理 | 用户提示 |
|---------|---------|---------|
| 节点名称为空 | 阻止保存 | "节点名称不能为空" |
| 节点名称超过 50 字 | 阻止保存 | "节点名称不能超过 50 字" |
| 父节点不存在 | 阻止保存 | "父节点不存在，请重新选择" |
| 超过层级限制 | 阻止保存 | "最多支持 5 层嵌套" |

### 12.2 批量导入异常

| 异常情况 | 系统处理 | 用户提示 |
|---------|---------|---------|
| CSV 格式错误 | 拒绝导入 | "文件格式错误，请检查 CSV 格式" |
| 文件过大（>10MB） | 拒绝导入 | "文件不能超过 10MB" |
| 部分行格式错误 | 部分成功 | "成功 X 条，失败 Y 条（显示失败原因）" |

### 12.3 网络异常

| 异常情况 | 系统处理 | 用户提示 |
|---------|---------|---------|
| 保存时网络断开 | 保存失败 | "网络连接失败，请检查网络后重试" |
| 加载时网络超时 | 展示空状态 | "加载超时，请刷新页面" |
