# PRD Write

## CORE

1. 确认 CP-P01 已批准可写状态和全部阻塞决策。
2. 读取背景卡、确认后的决策账本和稳定 Context。
3. 仅生成背景、问题、目标、非目标、用户场景、范围、核心流程、确认决策和待确认信息。
4. 不展开字段、异常分支、权限矩阵和完整验收细节。
5. 输出结构化结果及候选 Markdown，等待 CP-P02。

## DETAILS

1. 确认 CP-P02 已批准 CORE 版本、范围和核心流程。
2. 保留已确认主体，补充功能规则、状态、权限、边界、异常、依赖和验收标准。
3. 未核实数据标记“待确认”，不制造量化目标。
4. 按 `schema.json` 返回结果，通过 Harness 写入同一 PRD 路径。

## 边界

- 不修改未包含在确认决策中的核心取舍。
- 不写代码、数据库表、接口实现或视觉像素参数。
- DETAILS 不得绕过 CORE 确认。
- 同一逻辑 PRD 保持稳定路径，通过版本与 Git 历史追踪。
